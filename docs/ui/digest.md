# AriaDesk UI Design Digest

> 前端实现基准文档。所有界面开发以此为准；与本文冲突时以本文为准。
> 适用：Wails 桌面端（Vue 3 + Vite + Element Plus 定制主题），Windows 10/11。

---

## 1. Design Read

Windows 桌面工具控制台（aria2 管理器），Linear 式克制语言，单一饱和蓝强调 + Zinc 中性灰，工具可信度优先于视觉表现。

**Dials**：`DESIGN_VARIANCE: 4` / `MOTION_INTENSITY: 3` / `VISUAL_DENSITY: 6`

- 布局规整对称（工具界面，无 hero / 无创意留白）
- 动效仅微反馈，全部可降级
- 数据密度中高：统计卡片 + 高密度任务列表

## 2. 色彩 Tokens

### 2.1 强调色（全站唯一）

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#2E62F6` | 主按钮、选中 Tab、链接、进行中任务标题 hover |
| `--brand-hover` | `#2553D8` | 主按钮 hover |
| `--brand-active` | `#1E45B8` | 主按钮按下 |
| `--brand-soft` | `#EBF0FE` | 选中态背景、图标底色块（light） |

语义色仅表状态，不得装饰性使用：

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--success` | `#16A34A` | `#4ADE80` | 已连接徽标、下载完成 |
| `--warning` | `#D97706` | `#FBBF24` | 等待/暂停提示 |
| `--danger` | `#DC2626` | `#F87171` | 删除、错误横幅 |

**禁止**：紫色/紫蓝渐变、霓虹 glow、mesh 渐变背景、纯黑 `#000000`。

### 2.2 中性色（Zinc，冷暖不混用）

| Token | Light | Dark |
|---|---|---|
| `--bg` 页面底 | `#FAFAFA` | `#09090B` |
| `--surface` 卡片/输入 | `#FFFFFF` | `#18181B` |
| `--surface-2` 嵌套块/统计图标底 | `#F4F4F5` | `#27272A` |
| `--border` 描边 | `#E4E4E7` | `#3F3F46` |
| `--text-1` 主文字 | `#18181B` | `#FAFAFA` |
| `--text-2` 次要 | `#52525B` | `#A1A1AA` |
| `--text-3` 弱化（placeholder） | `#A1A1AA` | `#71717A` |

暗色模式：跟随系统 `prefers-color-scheme`，设置页可手动覆盖（`data-theme="dark"` 挂根节点）。全应用单主题族，禁止页面中部出现反色块。

## 3. 字体

| 场景 | 栈 | 规则 |
|---|---|---|
| 中文/界面 | `system-ui, "Microsoft YaHei", "PingFang SC", sans-serif` | 系统栈，不引入中文字体文件 |
| 数字（速率/进度/任务数/端口） | `"JetBrains Mono", ui-monospace, monospace` | 自托管 `@font-face` + `font-display: swap`；tabular 数字保证列对齐 |

字号阶梯（桌面窗口 100% 缩放基准）：

| 角色 | 大小 / 行高 / 字重 |
|---|---|
| 页面标题 | 20px / 28 / 600 |
| 卡片数值（统计） | 24px / 32 / 700，等宽 |
| 区块标题 / 卡片标题 | 15px / 24 / 600 |
| 正文 / 列表 | 13px / 20 / 400 |
| 辅助说明 | 12px / 18 / 400，`--text-2` |
| 按钮 | 13px / 20 / 500 |

## 4. 形状与间距

- **圆角锁定**（唯一规则，全局一致）：卡片/输入框 `8px`，按钮 `6px`，标签/徽标 pill 全圆角
- **间距基数** 4px；常用：组件内 `8/12/16`，卡片 padding `16/20`，区块间距 `20/24`
- **描边**：`1px solid var(--border)`；阴影仅用于弹层（弹窗/下拉），卡片不用投影，用 `border` 分层
- 内容区 `max-width: 1200px` 居中，窗口最小尺寸 960 × 640

## 5. 组件规范

### 5.1 按钮

| 类型 | 规格 |
|---|---|
| Primary | `--brand` 底 + 白字；hover `--brand-hover`；active `scale(0.98)`；禁用 40% 透明度 |
| Default | `--surface` 底 + `border` + `--text-1` 字 |
| Danger | 仅删除/停止场景，outline 样式（`--danger` 边+字），确认动作才用实心 |
| 尺寸 | 高 32px（工具栏主尺寸），padding 0 12px，标签 ≤ 4 字（"新建任务"） |
| 规则 | 同一意图全站一个标签；标签一行显示不下就改短文案，不加宽 |

### 5.2 输入框 / 表单

- Label 在输入框上方（12px / `--text-2`），placeholder 仅作示例不作标签
- 高 32px，圆角 8px；focus 环 `--brand` 35% 透明度 + 1px 边
- 错误文案在输入框下方，12px `--danger`；表单元素与背景对比度满足 WCAG AA

### 5.3 卡片（统计卡片）

- `--surface` 底 + 1px border，圆角 8px，padding 20px
- 结构：左侧 40×40 图标底块（圆角 8px，`--brand-soft` 底 + `--brand` 图标；语义卡片用对应语义色 soft 底）+ 右侧「12px 标签 / 24px 等宽数值」
- 四张等宽网格（`grid-cols-4`，gap 16），无阴影

### 5.4 状态徽标（全页唯一合法圆点）

连接徽标 pill 全圆角，内部 8px 圆点 + 文案，三种语义：

| 状态 | 配色 | 文案 |
|---|---|---|
| 未安装 | `--text-2` 圆点 / `--surface-2` 底 | "未安装 aria2" |
| 未连接 | `--danger` 圆点 / danger 10% 底 | "未连接" |
| 已连接 | `--success` 圆点 / success 10% 底 | "已连接 (N 个进行中)" |

除此外禁止任何装饰性彩色圆点。

### 5.5 任务列表

- Tab 工具栏 + `divide-y` 行分隔（不是逐行卡片）
- 行高 56px：图标 32px + 双行信息（文件名 13px 600 / 第二行 12px `--text-2`：进度% · 速率 · 大小）+ 右侧操作图标按钮
- 进度条：4px 高，`--brand` 填充，无底槽轨道色块（`--surface-2` 细槽）
- 操作图标：暂停/恢复/删除/打开目录，20px，`--text-2` hover 变 `--text-1`，危险操作 hover 变 `--danger`

### 5.6 Tab

- 文字 Tab（非胶囊），选中：`--brand` 字 + 600 字重；无下划线或 2px `--brand` 下划线（二选一全站一致，推荐无下划线靠字色字重区分）
- 禁用 Element Plus 默认的胶囊/边框 tab 样式

### 5.7 弹窗（新建任务 / 确认）

- 圆角 8px，`--surface` 底，头部标题 15px/600 + 关闭 ×，遮罩 `rgba(0,0,0,0.45)`
- 确认弹窗（删除）：danger 主按钮在右，文案具体（"删除任务"而非"确定"）

## 6. 页面结构

### 6.0 应用框架（左侧边栏导航，全局）

- 布局：左侧边栏 136px（`--surface` 底、右边 1px border）+ 右侧主内容区（`max-width: 1200px` 居中，padding 24）
- 边栏顶部：品牌标（20px `--brand` 圆角块 + 图标）+ "AriaDesk" 14px/600
- 导航项：图标 16px + 文字 13px，行高 34px，圆角 6px，间距 2px：

| 页面 | 职责 |
|---|---|
| 首页 | 连接区 + 统计卡片 + 任务列表（功能四） |
| 管理 | aria2 检测/安装/版本、启动/停止、RPC 密钥配置、默认下载目录（功能一、三） |
| 设置 | 开机自启、关闭行为（退出/隐藏到托盘）、aria2 随应用启动、关于（功能二） |

- 选中态：`--brand-soft` 底 + `--brand` 字 + 600 字重；hover：`--surface-2` 底
- 导航是应用级路由切换（Vue Router），选中项与路由同步
- 不放版本号、不放装饰元素

### 6.1 首页（主界面，对齐参考图）

主内容区纵向四段，无 hero 概念，首屏直达内容：

1. **连接区**（一条 surface 横条）：`RPC 地址(只读 localhost)` + `端口(6800)` + `RPC 密钥(只读掩码 •••)` + `连接/刷新(Primary)` + 右侧状态徽标
2. **统计卡片 ×4**：当前下载速率 / 当前上传速率（等宽 B/s，自动单位 KB/s MB/s）/ 进行中任务 / 等待·已暂停
3. **任务工具条**：Tab（进行中 / 等待中·暂停 / 已完成·停止）左；右对齐按钮组：新建任务(Primary) · 暂停全部 · 恢复全部 · 清理已完成
4. **任务列表区**：空态 = 居中下载图标 + "此列表中没有下载任务" + 12px `--text-2`

### 6.2 安装引导（aria2 未安装时，替换主内容区）

aria2 未安装时，首页/管理的主内容区整体替换为引导卡片（左侧边栏保持可用，可去设置页）：

- 居中卡片（max-width 480px）：标题"未检测到 aria2" + 说明文案一行（12-14px `--text-2`）
- 大按钮"一键安装 aria2"（Primary，高 40px）
- 安装中：按钮变 loading + 进度文本（捕获 winget 输出关键行）
- 安装完成：显示 `aria2c 1.36.0 已安装`（success 色）+ "启动 aria2"按钮

### 6.3 管理页（功能一 + 功能三）

主内容区表单卡片（max-width 720px），分区标题 15px/600 + 分区间距 24：

- **aria2 状态**：检测状态行（未安装 / 已安装 v1.36.0）+ 一键安装按钮（仅未安装时）+ 启动 / 停止 aria2 按钮 + 运行状态徽标
- **RPC**：RPC 密钥输入框（掩码 + 眼睛切换可见，旁边"重新生成"按钮，保存写 `token.pass`）、RPC 端口输入
- **下载**：默认下载目录（输入框 + 浏览…按钮，保存时校验目录存在可写）

开关组件：40×20 pill，开 = `--brand`，关 = `--border`。

### 6.4 设置页（功能二）

表单卡片（max-width 720px），分区标题 + 分区间距 24，不设二级导航（避免与左侧边栏双重导航）：

- **启动**：开机自启动开关、aria2 随应用启动开关
- **关闭行为**：单选（直接退出 / 隐藏到托盘）+ 说明文案一行
- **关于**：AriaDesk 版本、aria2 版本（只读）、日志查看入口、打开数据目录

## 7. 动效（MOTION 3）

白名单（全部 `cubic-bezier(0.16, 1, 0.3, 1)`，且 `@media (prefers-reduced-motion: reduce)` 下全部退化为无动画）：

| 元素 | 动效 |
|---|---|
| 按钮 | hover 底色 0.15s；active `scale(0.98)` 0.1s |
| 统计数值 | 数值变化 0.3s 过渡（速率跳变不闪烁） |
| 任务列表行 | 进入 stagger fade-up，≤ 200ms，间隔 30ms |
| 弹窗 | 进入 scale 0.98→1 + fade 0.2s |
| Tab/徽标状态切换 | 颜色 0.2s 过渡 |

禁止：滚动劫持、视差、无限循环装饰动画、骨架屏 shimmer 以外的任何循环动效。每个动效必须回答"传达了什么状态/反馈"，回答不出就删掉。

## 8. 图标

- 统一 `@element-plus/icons-vue`，全站一套；stroke/填充风格不混用其它库
- 尺寸阶梯：16（辅助/输入框内）/ 20（行操作）/ 24（统计卡片）/ 32（空态）
- 禁止手绘 SVG 图标、禁止 emoji 作为界面元素

## 9. 状态完整性检查表（每屏交付前必过）

- [ ] Loading：骨架屏形状对齐最终布局（卡片 4 块灰色块、列表 5 行灰色条）
- [ ] Empty：图标 + 一句话 + 引导按钮（如适用）
- [ ] Error：RPC 不可达时连接区下方红色横幅 + 重试按钮；表单错误行内显示
- [ ] Disabled：aria2 未启动时任务操作按钮组整组禁用 + tooltip 说明原因
- [ ] 未安装态：首页整体替换为安装引导页（不展示半残控制台）

## 10. 文案纪律

- 按钮标签 ≤ 4 字优先；同一意图全站一个文案
- 无版本号装饰标签、无 `v1.0`/`BETA` 徽标
- 无装饰性圆点/分隔符堆砌（`·` 每行最多 1 处）
- 数字格式：速率自动单位（B/s → KB/s → MB/s，一位小数）；进度百分比整数
- 确认文案具体化："删除该任务？"按钮"删除"；不写真值"确定"
